# Scope and Non-Goals

## In MVP
Starter plus annual 365-day Basic/Pro subscriptions; public card;
authentication; Starter manage/claim; custom URL; QR; VCF; themes; social
links; catalog; Maps; WhatsApp Pro; Midtrans abstraction; basic admin; ID/EN UI
structure.

## Out of MVP
NFC hardware, teams, custom domain, CRM, appointment, lead automation, native
app, marketplace, AI content/design, and lebih dari satu kartu aktif per akun.
Provider-specific automated renewal collection remains paused with the Midtrans
integration work; this does not change the product rule that Basic/Pro are
annual subscriptions.
