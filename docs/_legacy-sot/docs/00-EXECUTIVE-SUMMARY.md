# Executive Summary

Digital Identity Platform membantu pengguna membuat dan membagikan identitas profesional melalui satu halaman publik.

Pengunjung dapat melihat identitas/kontak, menyimpan `.vcf`, membuka website/lokasi, memindai QR, mengakses social links/katalog sesuai tier, dan menghubungi WhatsApp pada Pro.

Starter berfungsi sebagai acquisition tanpa login; Basic memberi akun/custom URL; Pro memberi branding dan fitur marketing lebih besar.

MVP berhasil bila pengguna dapat membuat, mengedit dengan aman, membagikan, menyimpan VCF, dan upgrade tanpa pelanggaran plan limit.
