# Accessibility Baseline

Semantic HTML, logical heading, label-input association, keyboard access, visible focus, touch target sekitar 44x44, tidak mengandalkan warna, modal focus trap, error summary, alt text, reduced motion, usable pada zoom 200%.

QR is never the only access method; provide selectable canonical URL and normal link.

Slug availability must be announced with an ARIA live region and not communicated by color alone.
The fixed domain prefix and editable slug must have a combined accessible description.

Theme previews require accessible names containing theme name, orientation, and plan.
Theme selection must be keyboard-operable.
Long contact values must not become inaccessible through clipping.
