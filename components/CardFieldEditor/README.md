# CardFieldEditor

Editable fields in user control panel:

## vCard-compatible fields

- Full Name
- Job Title
- Organization
- Office Phone
- Mobile Phone
- Email
- Website
- Address

## Web-only fields

- Google Maps URL
- Logo (Pro)
- Social Links (Basic/Pro limits)
- Catalog Items (Basic/Pro limits)

All themes render the same normalized field contract.
Changing a design never changes or duplicates contact data.
